# Security policy

Security fixes target the latest Jump release. Older releases do not receive
separate backports. This is a personal project with no guaranteed response time.

## Report a vulnerability

Do not publish vulnerability details, credentials, or an exploit in a public issue
or pull request.

Use [GitHub private vulnerability reporting](https://github.com/nathanclairmonte/jump/security/advisories/new)
when the repository offers it. If private reporting is unavailable, open an issue
that asks for a private contact method without describing the vulnerability.

A private report should include the affected Jump version, operating system,
reproduction steps, impact, and any proposed fix. Redact unrelated private data.
